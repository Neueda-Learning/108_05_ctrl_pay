## 🚀 Setup Instructions

### Installation
```bash
cd frontend
npm install
```

### Configuration
Create `.env` file:
```
REACT_APP_API_URL=http://localhost:8080/api
```

### Start Application
```bash
npm start
```

### Access
Open: `http://localhost:3000`
